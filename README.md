# sawaleb — تحليلي

لوحة تحليل عربية RTL لأصناف سوالب الفروع، تعمل بالكامل داخل المتصفح وتناسب النشر على GitHub Pages.

## التشغيل

افتح `index.html` مباشرة أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 3000
```

## الخصوصية والأمان

- ملفات CSV وExcel تُقرأ وتُحلل محليًا داخل المتصفح.
- لا توجد قاعدة بيانات أو API في هذه النسخة.
- لا توجد رموز أدمن أو أسرار في ملفات الواجهة.
- مستودع GitHub المستهدف خاص، بينما الموقع المنشور يمكن أن يكون عامًا.

## حدود GitHub Pages

GitHub Pages يستضيف ملفات ثابتة فقط. لذلك فإن المستخدمين، صلاحيات الأدمن، روابط المشاركة المؤقتة، والتقارير المحفوظة تحتاج لاحقًا إلى Backend آمن وقاعدة بيانات؛ لا ينبغي تنفيذها برمز ثابت داخل JavaScript.
